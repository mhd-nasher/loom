# Loom — Brand Assets

Drop the two brand images here with these exact names (the main `README.md` already references the
banner):

| File | What it is | Recommended size |
|------|-----------|------------------|
| `loom-icon.png` | The square Loom mark (loom frame, one gold thread) | 1024×1024 (square, transparent or dark bg) |
| `loom-banner.png` | The wide banner: loom mark + "Loom" + tagline | ~1774×887 (2:1) |

Usage:
- `loom-banner.png` → embedded at the top of the main `README.md`, and uploaded as the repo's
  **Social preview** in GitHub → Settings → General → Social preview.
- `loom-icon.png` → use as the GitHub profile/org avatar and as a favicon source.

Generation prompts for both images are in [`IMAGE_PROMPTS.md`](IMAGE_PROMPTS.md). They are tuned to sit
beside the sibling projects **[Cairn](https://github.com/mhd-nasher/cairn)** and
**[Bastion](https://github.com/mhd-nasher/bastion)** as a matched set.
